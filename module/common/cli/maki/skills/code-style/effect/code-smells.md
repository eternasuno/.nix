# Effect Code Smells

Check the installed Effect version, actual service contracts, cancellation, and resource ownership before changing composition.

- **Generator wrapper functions:** a function that only returns `Effect.gen`, or an `Effect.fn` result followed by `.pipe`, instead of `Effect.fn`/`Effect.fnUntraced` with combinators passed as extra arguments. Flag `Effect.fn` span names that do not match the function (`Service.method` for service methods) and errors raised with `yield*` but without `return`.
- **Indirect Effect construction:** `Effect.promise` or `new Promise` around throwing, rejecting, nullable, or callback sources where `Effect.try`, `Effect.tryPromise`, `Effect.fromNullishOr`, or `Effect.callback` with a finalizer applies.
- **HTTP transport or Promise-chain bypass:** flag HTTP requests bypassing fetch/Effect HttpClient and Promise `.then`/`.catch`/`.finally` chains around Effect execution or adapters. Use FetchHttpClient and direct Promise adapters with Effect composition, preserving security, cancellation, error channels, and cleanup. Effect.catch/catchTag/ensuring are valid Effect composition.
- **Hand-rolled HTTP client policy:** per-request base URLs, manual `response.ok`/status checks, retry loops, or `JSON.parse` of bodies where `HttpClient.mapRequest`, `filterStatusOk`, `retryTransient`, and `HttpClientResponse.schemaBodyJson` on one configured client apply.
- **Behavior outside services:** application capabilities exposed as free functions, module singletons, or hand-passed dependencies instead of a `Context.Service` with a static Layer. Flag services that skip `X.of`, lack an identifier with package and module path, or name Layers outside the `layer`/`layerNoDeps`/`layerTest` roles.
- **Service shape declared as a type alias:** a named Effect service shape declared with `type`, or a mix of `type` and `interface` across service shapes, breaks the service-shape convention. A local copy of an inline shape instead of `X["Service"]` is the same smell. Report it as a style finding, not a correctness defect.
- **Redundant ports and configuration services:** a port over a service Effect already provides (such as `HttpClient`), or a full Service holding a plain configuration value where `Context.Reference` or `Config` applies.
- **Overbroad environment:** compare required services with actual use. Acquire only needed services inside the Effect using them; preserve provider sharing, dependency order, and lifetime.
- **Reimplemented provider protocol:** inspect version-matched official adapters first. Compose supported Layers and decorate missing application policy instead of wrapping an entire client. Verify endpoint, timeout, credentials, redirects, tracing, and response lifetime.
- **Unnecessary async conversions:** compare direct supported callback, throw, or Promise adapters. Remove intermediate conversions only when cancellation and cleanup remain correct.
- **Manual validation and platform primitives:** hand-written type guards (`isRecord`, `isString`), manual parsing of untrusted input, decoders rebuilt per call, `Date`/`Date.now`, or `console` inside Effect code. Use `Predicate`, hoisted `Schema` decoders, `DateTime` with `Clock`, and `Effect.log*`.
- **Error-channel damage:** trace catches and rewrapping for lost information or conflation of expected failures, defects, and interruption. Translate only at an intentional boundary. Flag errors not defined with `Schema.TaggedError`, unknown causes not carried as `Schema.Defect()`, and long error unions where a tagged `reason` wrapper fits.
- **Leaking registrations or resources:** inspect acquisition failure, completion, interruption, and late callbacks where reachable. Preserve release and cleanup on all required paths. Flag resources opened without `acquireRelease`, listeners without finalizers, and detached forks instead of `Effect.forkScoped` in a scoped Layer.
- **Hand-rolled scheduling or batching:** sleep-and-retry loops, unbounded or unjittered retries, polling timers, or per-item lookups that `Schedule`, `Stream.fromEffectSchedule`, or `RequestResolver` express.
- **Scattered runtime execution:** `Effect.runPromise`/`runSync` inside application code, several `ManagedRuntime`s without a shared memo map, or a runtime never disposed. Run at the edge with `runMain`, `Layer.launch`, or one `ManagedRuntime`.
- **Duplicate execution forms:** identify actual consumers of Promise and Effect APIs before retaining both. Share one workflow rather than duplicating behavior.
- **Fragmented schema value types:** a value type split across named intermediate schemas, or checks applied after the brand or wrapper, obscures its rules. Rewrite it as one pipe: normalize, check, brand, wrap.
- **Hand-rolled discriminant dispatch:** a `kind`/`type` string union dispatched with `if` chains where the union selects workflow branches or crosses a boundary gives no exhaustiveness. Rewrite it as `Schema.TaggedUnion` with `match` or `Match.valueTags`; plain local data shapes may stay a TypeScript union.
- **Error payload shadows `Error.name`:** a tagged error whose payload has a `name` field replaces the error's own name (the Effect language service flags `errorPayloadShadowsName`). Rename the field to a specific key.
- **Ad hoc patch semantics:** compare patch types with the entity's writable fields. A missing field preserves, `Option.none()` clears, and `Option.some` sets; identity, ownership, and immutable fields never appear in a patch.
- **Manual test runtimes and fakes:** `Effect.runPromise` inside plain `it` blocks, real sleeps instead of `TestClock`, or fakes that are not `layerTest` Layers of the real service. Hidden missing fake members behind casts and shared `layer(...)` blocks whose tests depend on order are the same smell.
